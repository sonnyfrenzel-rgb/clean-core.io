# Gestaltungsentscheidungen (ADR-Log)

Jede Entscheidung, die `DESIGN.md` festlegt, mit Datum, Anlass und Begründung. `DESIGN.md` sagt, was gilt; dieses Log
sagt, warum. Eine neue Farbe, ein neuer Radius, ein neues Muster oder eine Abweichung davon bekommt hier einen Eintrag,
bevor sie in `DESIGN.md` steht. Einträge werden nicht gelöscht; eine überholte Entscheidung wird als *ersetzt durch*
markiert.

## Step 9 — content dates

```

```

No flags, no `--check`. It takes each route's newest *commit* date, skipping metadata-only
commits, so the content must be committed first. It exits 1 if a route has no git date or
fewer than three distinct dates exist (shallow-clone protection). Today's newest date is
2026-09-24; after a resync the dates reach the release week, and `tests/sitemap-guard.spec.ts`
fails unless `APP_RELEASE_DATE` is already at least the newest date minus one day — hence
step 3 first. Guards: `content-dates-guard`, `sitemap-guard`. Commit the result on its own.

    What to measure, without a third party · owner and lawyer decision

    Nothing below is presumed or built. Today the page counts nothing. Any count needs the owner's go and the lawyer's view, and the privacy notice would need a line before the first count.

    What it means legally (for the conversation with the lawyer, not a legal assessment)

    • No cookie and nothing written to the device: counts are increments on the server when the page asks its own origin. Whether a server-side count of a request is processing of personal data depends on whether IP or user agent is kept; the proposal keeps neither.
    • The request still carries the IP to Cloud Run as every page request does; the count must not log it beyond what the platform already logs.
    • The privacy notice needs one sentence: which counts, aggregated per day, no cookie, no profile, retention.
    • Product-side totals (sign-up, first project, first analysis) exist already; linking a sign-up to a showcase visit would be new processing. The proposal does not link them.

    How the BPMN is drawn

    Chosen: pre-rendered SVG from the product's renderer. A build script loads the demo's own BPMN 2.0 file (buildDemoProject().documentation.process.model.xml, 11 levels, 94 elements, data stores, error ends, boundary events, send tasks, sub-process markers, the "Reconstructed … without a language model" annotation) into bpmn-js 18.28.0 NavigatedViewer with the product's settings (components/process-map/bpmn-view.ts) and saves each level as SVG. Same notation, same layout, same labels as the product's map; 11 levels instead of the two asked for, because they cost little. Why not the inlined viewer bundle: it is 190 KB of minified script for a static page that only needs to show, select and open a level, and the pre-rendered SVG keeps the element ids for the clicks. The bpmn.io mark and licence notice are kept.

    Recommendation: A, the guide box in one fixed place, over the screen. Owner, 13.11.2026: the boxes must not jump; they may overlap, as long as each step first shows the whole screen. So the box no longer follows the explained part.

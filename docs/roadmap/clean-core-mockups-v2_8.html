What clean core means

Keep the SAP core standard: extensions use only released, upgrade-stable interfaces — in-app with ABAP Cloud or side-by-side on SAP BTP.

The four levels

  1. AReleased SAP APIs and extension points
  2. BClassic SAP APIs following SAP's recommendations
  3. CInternal SAP objects — only with a changelog check before each upgrade
  4. DNot recommended — modifications, implicit enhancements, writes to SAP tables

Levels follow SAP's clean core level concept. The level shown for an object is our reading of SAP's published data — an orientation, never part of a signed audit pack. Confirm with ABAP Test Cockpit.

Where the evidence comes from

  1. Your ABAP source — every statement with a line anchor
  2. Deterministic engine · rule set levels/1.3 engine
  3. SAP's published data: Cloudification Repository (release states, successors) and SAP's object classification · 32,103 objects · synced 2026-09-07
  4. Your imports, optional: ATC results, usage data
  5. A language model — only for names and wording
